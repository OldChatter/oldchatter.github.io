# OldChatter

A voice and video chat room app in the classic style: join public rooms, talk on the mic, share your webcam, send private messages, and keep a contact list.

This repository only holds the downloads and a description. The source code is not published.

## Download

Get the latest builds from the [Releases](../../releases/latest) page.

| Platform | File |
|----------|------|
| Windows 10 / 11 | `OldChatterSetup.exe` |
| Android 6 or newer | `OldChatter.apk` |

There is also a Telegram Mini App with the same rooms and contacts.

## What you can do

- Chat in public rooms, grouped by category
- Talk with voice and share your webcam in a room
- Send private messages and whispers
- Keep a contact list and see who is online
- Use animated smileys
- Set a profile picture, a status and a custom status message
- Choose who may message, invite or whisper to you (everyone, or only your contacts)

## Install

**Windows:** run `OldChatterSetup.exe`. Windows SmartScreen may warn about an unknown publisher because the installer is not code-signed; choose *More info*, then *Run anyway*.

**Android:** open `OldChatter.apk` on the phone and allow installing from this source when asked. If you have an older version installed that was signed with a different key, uninstall it first.

## Accounts

Create a free account inside the app. One account can be signed in on one device at a time: signing in somewhere else signs the first device out.
