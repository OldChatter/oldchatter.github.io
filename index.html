Get started

  1. Download the app for your device above.
  2. Windows: run the installer. If SmartScreen warns about an unknown publisher (the installer is not code-signed), choose More info, then Run anyway.
  3. Android: open the APK and allow installs from this source when asked. If you have an older version signed with a different key, uninstall it first.
  4. Create a free account inside the app and pick a room.

One account can be signed in on one device at a time. Signing in somewhere else signs the first device out.
